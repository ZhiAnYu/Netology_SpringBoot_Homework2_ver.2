# Отчет по выполнению задачи: Dockerization Spring Boot Application

## 1. Что использовано (Инструменты и технологии)

*   **Операционная система:** Windows 10/11 с подсистемой WSL2 (Ubuntu).
*   **Среда разработки:** IntelliJ IDEA Community Edition 2025.
*   **Язык программирования:** Java 17 (OpenJDK 17.0.6_10).
*   **Сборщик проектов:** Apache Maven (`mvnw`).
*   **Фреймворк:** Spring Boot Web MVC (версия 4.0.3), Tomcat 11.0.18.
*   **Контейнеризация:** Docker Engine (версия 29.3.0) внутри Ubuntu (без Docker Desktop).
*   **Оркестрация:** Docker Compose (плагин v2).
*   **Базовый образ:** `eclipse-temurin:17-jre-alpine` 

## 2. Что сделано (Ход работы и изменения)

### Подготовка окружения
1.  Отказ от использования Docker Desktop для Windows в пользу нативного Docker Engine внутри WSL2 (Ubuntu) для стабильности и производительности.
2.  Перенос исходного кода проекта из файловой системы Windows (`/mnt/c/...`) в нативную файловую систему Linux (`~/projects/...`) для корректной работы прав доступа и монтирования томов.

### Настройка Dockerfile
*   **Изменение базового образа:** Вместо устаревшего `openjdk:8` (указанного в первоначальном задании) использован современный образ `eclipse-temurin:17-jre-alpine`, соответствующий версии JDK проекта (Java 17).
*   **Оптимизация:** Добавлена директива `WORKDIR /app` и использован `ENTRYPOINT` для запуска приложения.

### Настройка docker-compose.yml
*   Создан манифест для автоматической сборки и запуска.
*   **Изменение порта:** Конфигурация изменена для запуска приложения на порту **9090** вместо стандартного 8080.
    *   Проброс портов: `9090:9090` (Хост : Контейнер).
    *   Переменная окружения: `SERVER_PORT=9090` передана в контейнер для динамической настройки Spring Boot при старте.

### Сборка и запуск
1.  Выполнена сборка проекта командой `./mvnw clean package -DskipTests`.
2.  Образ собран командой `docker compose up --build`.
3.  Контейнер запущен и успешно инициализировал контекст Spring.

## 3. Что получено (Результат)

*   **Рабочий Docker-образ:** Создан оптимизированный образ `resthomework2_my-auth-app` размером около ~200 Мб (благодаря использованию Alpine Linux).
*   **Запущенный сервис:** Приложение успешно работает в изолированном контейнере.
*   **Доступность:** Сервис доступен по адресу `http://localhost:9090`.
    *   Эндпоинт http://localhost:9090/authorize?user=user&password=234
ответ - ["READ"]
    *   Эндпойнт http://localhost:9090/authorize?user=admin&password=123
ответ - ["READ" , "WRITE", "DELETE"]
*   **Лог успешного старта:**
    ```text
    Tomcat started on port 9090 (http) with context path '/'
    Started RestHomework2MyApplication in 6.061 seconds
    ```
